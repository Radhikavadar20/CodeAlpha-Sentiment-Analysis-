# CodeAlpha-Sentiment-Analysis-
Sentiment Analysis project completed during CodeAlpha internship using Python and Natural Language Processing.


## 📌 Project Overview
This Sentiment Analysis project was completed during my CodeAlpha internship.

The project uses Python and Natural Language Processing (NLP) to analyze text and identify whether the sentiment is Positive, Negative, or Neutral.

## 🛠️ Technologies Used
- Python
- Natural Language Processing (NLP)
- Jupyter Notebook
- Text Processing
- Machine Learning

## 🎯 Objective
The main objective of this project is to understand and analyze the sentiment expressed in text data.

## 📊 Sentiment Categories
- Positive
- Negative
- Neutral

## 📁 Project Files
- `analysis.ipynb` – Jupyter Notebook containing the complete analysis
- `README.md` – Project documentation
- `.gitignore` – Git ignore configuration
